# Yarn Trails for iPhone and Android

Expo app. The plan is [`docs/mobile-app-plan.md`](../docs/mobile-app-plan.md).

Requires Node 22.13 or newer. From this folder:

```bash
npm start
```

Then open the iOS simulator or an Android device. `npm run ios` and `npm run android` do the same with a target.

The birth date is stored on the device under `babyBirthDate`. Sign-in and Plus are on screen. They do not call the network yet.
